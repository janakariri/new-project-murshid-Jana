# Murshid — Jana

Cumulative four-day Murshid Mini notebook aligned with the instructor’s SDA-AIE-213 course.

## Core submission
- `Murshid_Jana_Complete.ipynb`: one notebook for Days 1–4.
- Day 1 is preserved from Jana’s original `Murshid_lab1.ipynb` (original three lab sections were in one code cell).
- Days 2–4 cells are adapted directly from the instructor’s provided course reference and should be studied, run, and personalized before submission.
- `live_model_demo.ipynb` is an optional independent extension, not part of the required mock project.

## Run
Open the complete notebook in Google Colab, run all code cells in order on CPU, check asserts, and download the generated JSON results and `murshid_submission.zip`.
